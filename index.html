Woo Order Archive Manager
Plugin Development Open Source v1.0.0

A WooCommerce plugin I built from scratch to solve a real problem: order tables bloating to hundreds of thousands of rows and slowing down admin pages, checkout queries, and reports. The plugin physically moves order data into dedicated archive tables — not just a status change.

Transactional archiving — row-by-row copy inside DB transactions with full rollback if anything fails mid-copy
Verification layer — row counts checked between source and archive before a single live row is removed
Dry-run mode — preview the full archive cycle with no data changes, recorded in the activity log
Health score engine — weighted 0–100 score across DB size, integrity, archive coverage, and growth rate, cached via WP Cron
Onboarding wizard — first-run store scan with savings estimate before the user touches anything
WooCommerce Subscriptions guard — active subscription orders are automatically skipped
