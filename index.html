Woo Order Archive Manager WordPress Plugin · Database Optimization

WooCommerce stores slow down as order history grows — not because the store is big, but because everything lives in the same tables. This plugin solves that by migrating old orders into a dedicated set of archive tables, keeping the live database lean while preserving every record. Built on PHP 8.2 with full MySQL transaction support, it processes orders in configurable batches so large migrations don't time out or lock tables. A dry-run mode lets store owners preview what will be archived before anything moves — critical for production trust. The onboarding wizard makes first-time setup approachable without touching code.

7 archive tables Transaction safety Dry-run mode Batch processing Onboarding wizard WordPress.org ready

Multi-Biometric Voter Fraud Detection Python · Flask · Biometrics

Electoral fraud is hard to catch when identity verification is a single point of failure. This system layers three independent biometric checks — iris pattern, fingerprint, and facial recognition — so a voter must pass all three before a ballot is counted. Built with Python and Flask, the backend captures live biometric data at voting time and matches it against registered records in real time. Each modality runs independently, meaning a false positive on one doesn't grant access. Duplicate voting is caught at the identity layer, not after the fact.

Triple-modal verification Iris recognition Fingerprint matching Face detection Duplicate vote prevention Flask REST API
